# Security

Report security vulnerabilities or data incidents that affect this plugin or Collabute MCP to:

- legal@collabute.com
- privacy@collabute.com

If the issue affects a Cursor Marketplace listing or Plugin Data, also notify Anysphere at legal@cursor.com.

Please include:

- A description of the issue
- Steps to reproduce, if available
- The affected plugin version or MCP endpoint
- Whether Customer Data or Plugin Data may have been exposed

Do not file public GitHub issues for unpatched vulnerabilities.

Collabute uses TLS in transit and encrypts OAuth tokens and integration credentials at rest, as described in the [Privacy Policy](https://collabute.ai/privacy-policy) and [Terms of Service](https://collabute.ai/terms-and-conditions).
